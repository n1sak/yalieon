# Yalieon 🐶

**KRILLION FOR YALIES!**
https://www.youtube.com/watch?v=PnOtj-ZO2Ds
[![Watch Yalieon in action](https://img.youtube.com/vi/PnOtj-ZO2Ds/maxresdefault.jpg)](https://youtu.be/PnOtj-ZO2Ds)

Seven prompts. Twenty-five seconds each. One pixel bulldog stuck on top of Harkness Tower.

Rare answers drop him down the tower. 

## How we built it

Grok, of course!

We built this with Grok in Cursor. Then we hooked Cursor up to our Grok API so the questions use live data from Twitter with the keyword Yale! It also reads The Rumpus, the Yale Daily News, The Politic, and whatever else the web is saying about Yale today.
